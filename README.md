# My Screen Share — Android starter

Consent-based Android screen-capture starter. It does not secretly capture, bypass Android permission prompts, or send screen data remotely.

Included: Kotlin project skeleton, visible Android screen-capture permission flow, and foreground service notification.
Not included: WebRTC transport, remote viewer, deployed signaling server, or WhatsApp deep-link integration.

Open with Android Studio or a compatible cloud Android build environment. Acode alone cannot build an APK.
